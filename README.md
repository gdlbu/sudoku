# 专业数独解答器

由 **@山东好旱** 打造的轻量网页版数独求解工具，兼顾专业度与美感。支持题面录入、实时冲突提示、智能求解与深浅双主题，让你在桌面或移动端都能快速验证数独题目。

## 功能特色

- **双主题界面**：一键切换浅色 / 暗色主题，夜间观感柔和、白天阅读通透。
- **九宫格视觉引导**：交替着色的 3×3 宫与动态焦点高亮，让复杂题面一目了然。
- **智能求解引擎**：位掩码 + MRV 的回溯算法快速筛选候选，复杂题目也能稳定求解。
- **实时校验与提示**：输入时即时标记冲突，求解后高亮新增数字，便于核对题面。
- **示例 / 挑战题库**：一键加载经典题或高难度挑战，验证算法能力的同时快速上手。
- **响应式体验**：采用自适应布局与细腻过渡动画，在手机、平板与桌面端均表现专业。

## 使用方式

1. 克隆或下载本仓库：

   ```bash
   git clone https://github.com/<your-name>/sudoku.git
   cd sudoku
   ```

2. 直接用浏览器打开根目录下的 `index.html` 即可使用。

   > 如需在局域网分享，可运行一个本地服务器，例如：
   >
   > ```bash
   > python3 -m http.server 8000
   > ```
   >
   > 然后访问 `http://localhost:8000`。

3. 在棋盘中录入题面（支持键盘输入 1-9），或点击“加载经典示例 / 加载挑战题”体验预设题目。
4. 点击“开始求解”按钮，即可快速得到唯一解并查看填入结果。
5. 如需重新开始，可点击“清空棋盘”；主题开关可在浅色与暗色之间一键切换，并记住你的偏好。

## 技术实现

- **界面层**：HTML + CSS 构建的玻璃拟态界面，头部展示作者署名与主题开关，CSS 变量驱动浅色 / 暗色双主题，交替着色的九宫格强化结构可读性。
- **算法层**：`solver.js` 中实现基于位掩码的 MRV 回溯求解器，实时过滤候选、自动判冲突，即便面对高难度题目也能高效产出唯一解。
- **交互层**：原生 JavaScript 完成棋盘构建、状态提示、主题记忆（LocalStorage）与求解流程，无需任何第三方依赖。
