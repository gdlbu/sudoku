# 专业数独解答器

由 **@山东好旱** 打造的轻量网页版数独求解工具，兼顾专业度与美感。支持题面录入、实时冲突提示、动画化求解与多种主题模式，让你在桌面或移动端都能快速验证数独题目。

## 功能特色

- **双主题界面**：内置浅色 / 暗色模式，并支持跟随系统偏好，按钮一键切换更护眼。
- **九宫格视觉引导**：交替着色的 3×3 宫与动态焦点高亮，让复杂题面一目了然。
- **智能求解引擎**：在 MRV 基础上加入必填数（Naked Single）、唯一候选（Hidden Single）等推理策略，再配合深度回溯，复杂题目也能稳健求解。
- **实时校验与可视化**：输入时即时标记冲突，求解过程逐格呈现推理轨迹。
- **示例 / 挑战题库**：一键加载经典题或高难度挑战，验证算法能力的同时快速上手。
- **响应式体验**：采用自适应布局与流畅动画，在手机、平板与桌面端均表现专业。

## 使用方式

1. 克隆或下载本仓库：

   ```bash
   git clone https://github.com/<your-name>/sudoku.git
   cd sudoku
   ```

2. 直接用浏览器打开根目录下的 `index.html` 即可使用。

   > 如需在局域网分享，可运行一个本地服务器，例如：
   >
   > ```bash
   > python3 -m http.server 8000
   > ```
   >
   > 然后访问 `http://localhost:8000`。

3. 在棋盘中录入题面（支持键盘输入 1-9），或点击“加载经典示例 / 加载挑战题”体验预设题目。
4. 点击“开始求解”按钮，即可观看动画化推理过程并获得最终答案。
5. 如需重新开始，可点击“清空棋盘”；“切换深浅模式”可在浅色、暗色与系统模式之间循环。

## 技术实现

- **界面层**：HTML + CSS 构建的玻璃拟态界面，使用自定义 CSS 变量管理浅色 / 暗色主题，交替着色的九宫格提升可读性。
- **算法层**：`solver.js` 中实现基于 MRV 的回溯求解器，结合 Naked Single、Hidden Single 等约束传播策略，显著减少搜索分支。
- **交互层**：原生 JavaScript 完成棋盘构建、状态提示、主题记忆（LocalStorage）与求解动画，无需任何第三方依赖。
