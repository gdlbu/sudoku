# 专业数独解答器

一个轻量、颜值高且功能强大的网页版数独求解工具，支持题面录入、冲突校验、动态可视化求解等功能。

## 功能特色

- **即时校验**：录入时即时检测重复冲突，问题格会高亮提示。
- **智能求解**：基于 MRV（最小剩余值）策略 + 回溯的高效算法，可快速求解绝大多数题目。
- **可视化过程**：求解时逐格展示填数过程，直观了解解题思路。
- **示例题面**：一键加载经典题面，便于体验与演示。
- **响应式设计**：桌面端与移动端均有良好体验。

## 使用方式

1. 克隆或下载本仓库：

   ```bash
   git clone https://github.com/<your-name>/sudoku.git
   cd sudoku
   ```

2. 直接用浏览器打开根目录下的 `index.html`，即可使用。

   > 如需在局域网分享，可运行一个本地服务器，例如：
   >
   > ```bash
   > python3 -m http.server 8000
   > ```
   >
   > 然后访问 `http://localhost:8000`。

3. 在棋盘中录入题面（支持键盘输入 1-9）。
4. 点击“求解”按钮，观看求解过程并获取最终答案。
5. 如需重新开始，可点击“清空棋盘”；“加载示例”可快速体验工具。

## 技术实现

- **界面**：HTML + CSS 构建的桌面级 UI，使用 CSS Grid/Table 实现 9×9 棋盘与 3×3 高亮边界。
- **逻辑**：`solver.js` 中实现的回溯求解器，结合 MRV 启发式与候选集计算以减少搜索。
- **用户体验**：状态提示、按钮交互与动画均通过原生 JS 实现，无需额外依赖。
